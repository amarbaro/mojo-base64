# v0.1.0

## Changes

- Base16, Base32, Base32hex, standard and URL-safe Base64 byte codecs.
- Allocating and append APIs, strict Base64, casefold and Base32 map01.
- Real CPython vectors, bitwise Mojo oracle and compiling behavioral mutants.
- Correct current CPython strict padding order, data counts and parameter repr.

## Limits

Empty optional byte lists represent None; Python exception types differ.
String inputs, encode altchars, Base85 and line wrapping are unsupported.
Scratch allocations remain in decoders and several append wrappers.

## Verified

MOJO=.venv/bin/mojo scripts/ci.sh: oracle replay, golden replay, random bitwise
oracle, behavioral mutants, API and quickstart. scripts/nightly.sh checks the
nightly package and the same golden/brute/API/example entry points.
